# 💻 Ram Divgi - Personal Portfolio Showcase

Welcome to my personal portfolio repository! This is a modern, highly interactive, and elegant portfolio website built to present my projects, skills, professional journey, and achievements.

## 🚀 Live Demo

You can view the live website [here](https://ramdivgi.github.io/portfolio/)
---

## 🌟 Website Sections

- **Home (Hero)**: Highly interactive landing section featuring a unique "scratch-reveal" canvas effect and animated developer introduction.
- **About Me**: Professional summary, personal insights, and interactive components.
- **Experience**: Timeline showcasing my professional career trajectory.
- **Education**: Detailed timeline of my academic background and degrees.
- **Skills & Services**: Visual representations of my technical stack and the specific services I offer.
- **Projects**: Showcase of my best work (including AI/IoT integrations) complete with images, tech stacks, and links.
- **Achievements**: Highlights of major milestones, including patent filings.
- **Contact**: Functional contact form powered by EmailJS, alongside my social and professional links.

---

## ⚡ Key Features

- **Clean & Modern UI/UX**: Premium aesthetic with dark-mode styling and glassmorphism elements.
- **Advanced Animations**: Buttery smooth scroll animations, fading letters, and interactive hover effects powered by Framer Motion.
- **Fully Responsive**: Optimized for Desktop, Tablet, and Mobile devices (including precision mobile image fitting).
- **Serverless Contact Form**: Direct email messaging capabilities without the need for a backend server.
- **Fast Performance**: Built on Vite for lightning-fast loading and optimized asset delivery.

---

## 🛠 Technologies Used

- **React.js** – Component-based UI architecture
- **Vite** – Ultra-fast development environment and bundler
- **JavaScript (ES6+)** – Application logic and interactivity
- **Vanilla CSS3** – Highly customized styling, media queries, and responsive layouts
- **Framer Motion** – Complex scroll animations and transitions
- **EmailJS** – Serverless email integration
- **Font Awesome & React Icons** – Clean, scalable vector icons

## 🚀 How to Run Locally

If you'd like to run this project on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RamDivgi/portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd portfolio
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   *The app will be running at `http://localhost:5173/RamPortfolio`*
